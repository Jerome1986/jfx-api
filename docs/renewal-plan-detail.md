# 焕新方案详情图片

- detail 由文字改为 string[]，新增省略时保存 []，更新省略时保持原值，传 [] 清空。
- 元素必须是非空白字符串，不接受 null、单字符串或非字符串元素。列表和详情接口返回数组。
- 后台支持批量上传、删除、预览和编辑回显；按文件列表顺序提交，上传期间禁止保存，失败文件不提交。方案详情选填。
- 小程序在服务明细之后按顺序展示详情图片，点击预览，空数组隐藏该区域。
- images、cover、shareImage 仍是独立字段。
- 迁移：20261101010000_renewal_plan_detail_array；空旧详情初始化为 []，非空旧文字不自动转换为图片。

## 合并详情入口

仅保留 detail 图片数组，移除重复 images 字段与上传入口。列表和详情统一展示 detail。迁移 20261101020000_merge_renewal_plan_images 会先将原 images 图片追加到 detail，然后删除冗余列；cover 和 shareImage 保持独立。
